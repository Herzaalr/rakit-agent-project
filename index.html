Rakit AI agent lo sendiri pake Hermes.
Lengkap, gak semena-mena.

Panduan step-by-step dari nol: install, kasih kepribadian (SOUL.md), kasih skill (SKILL.md), set memory, pasang pagar biar agent-nya gak ngaco, simpen rahasia dengan bener, terus konek ke Telegram dan X.

Mulai dari install →Langsung ke boundaries

Hermes itu apa sih?

Hermes Agent itu agent open-source dari Nous Research yang jalan di terminal lo. Dia bisa pegang shell, baca/tulis file, punya memory yang nempel antar sesi, belajar skill sendiri, bisa dijadiin bot Telegram/Discord/WhatsApp, dan bisa dijadwalin (cron). Yang bikin dia enak: hampir semua "otak"-nya cuma file markdown di ~/.hermes/. Jadi lo bisa ngatur semuanya pake text editor.

Anatomi folder ~/.hermes/

tree ~/.hermes
~/.hermes/
├── config.yaml     # setting non-rahasia: model, terminal, memory, toolsets
├── .env            # API key, bot token, password  ← RAHASIA DI SINI
├── auth.json       # credential OAuth (Nous Portal, dll)
├── SOUL.md         # identitas agent, slot #1 di system prompt
├── memories/       # MEMORY.md + USER.md (ditulis si agent)
├── skills/         # SKILL.md per skill
├── cron/           # job terjadwal
├── sessions/       # sesi gateway (Telegram dll)
└── logs/           # errors.log, gateway.log (secret auto-redact)

Siapa nulis apa?

FileIsiYang nulis
SOUL.mdKepribadian, nada bicara, gayaLo
USER.mdProfil lo: nama, preferensiAgent (via tool memory)
MEMORY.mdCatatan si agent: fakta environment, kebiasaan projectAgent
AGENTS.mdAturan per-project: command, port, struktur repoLo, di folder project
SKILL.mdProsedur "cara ngerjain X"Lo, agent, atau install dari hub
.envAPI key, token, passwordLo. Bukan memory.

Prinsip gampangnya: SOUL.md = siapa dia, USER.md = siapa lo, MEMORY.md = yang dia pelajarin, AGENTS.md = yang project butuhin, .env = rahasia.
