# Rakit Agent pake Hermes

Panduan rakit AI agent pribadi pake Hermes Agent (Nous Research). Static site, tanpa build step.

Author: [herzaalr](https://github.com/herzaalr)

## Jalanin lokal

```bash
python3 -m http.server 8080
```

## Deploy

- **Vercel**: import repo ini → Framework Preset "Other" → Deploy.
- **GitHub Pages**: Settings → Pages → Source: branch `main`, folder `/ (root)`.
