step 01

Install & setup

Target halaman ini: Hermes kepasang, udah bisa diajak ngobrol di terminal. Sisanya (bot, skill, dll) nyusul.

1. Install

Butuh Linux, macOS, atau WSL2 di Windows. Satu baris:

bash
$ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Iya, ini pipe-to-shell. Lucunya, Hermes sendiri bakal nge-flag pola curl | bash sebagai command berbahaya kalau agent-nya yang jalanin. Buat install awal gapapa, tapi biasain baca script-nya dulu kalau mau paranoid: curl -fsSL ...install.sh -o install.sh && less install.sh.

2. Setup model (otaknya)

Ada dua jalur:

Jalur cepat: Nous Portal

bash
$ hermes setup --portal   # login, set Nous jadi provider, nyalain Tool Gateway

Satu langganan dapet akses banyak model + tool gateway (web search, image gen, TTS, browser). Gak perlu juggling API key.

Jalur manual: pake API key sendiri

bash
$ hermes setup            # wizard lengkap
$ hermes model            # cuma ganti provider/model
$ hermes tools            # nyalain/matiin tool

Bisa OpenRouter, Anthropic, OpenAI, atau endpoint lokal (Ollama / vLLM) via custom endpoint. Kalau pake API key, wizard bakal nyimpen ke ~/.hermes/.env, bukan ke config.

3. Ngobrol pertama

bash
$ hermes                     # mode chat interaktif
$ hermes chat -q "halo, lo siapa?"   # single query, langsung keluar

Kalau dia jawab, selamat, otaknya nyala. Di dalam chat ada slash command penting:

CommandFungsi
/contextLiat apa aja yang masuk system prompt (SOUL, memory, skills). Berguna banget buat debug.
/skillsDaftar skill yang kepasang
/personalityGanti gaya sementara (overlay, bukan edit file)
/new atau /resetSesi baru. Perlu kalau abis edit SOUL.md / memory supaya kebaca.
/yoloMatiin approval berbahaya. Jangan, kecuali di container sekali pakai.

4. Kenalan sama config.yaml

Semua setting non-rahasia ada di ~/.hermes/config.yaml. Urutan prioritas: argumen CLI > config.yaml > .env > default bawaan.

bash
$ hermes config get model
$ hermes config set memory.write_approval true
$ hermes config set OPENROUTER_API_KEY sk-...   # key otomatis dirutein ke .env, bukan config.yaml

5. (Opsional) Profile: beberapa agent sekaligus

Mau satu agent buat coding, satu buat bot Telegram pribadi, satu buat riset? Pake profile. Tiap profile = folder ~/.hermes/profiles/<nama>/ sendiri dengan config, .env, SOUL.md, memory, dan skill terpisah. Jadi kepribadian dan rahasia gak kecampur.

bash
$ hermes profile create riset
$ hermes -p riset            # jalanin pake profile riset
$ hermes profile list

Buat konten, profile ini enak: lo bisa demo "agent galak" vs "agent kalem" cuma dengan ganti -p.
